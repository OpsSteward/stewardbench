# StewardBench brand assets

Status: Approved concept; final repository-ready artwork is not yet available.

## Approved identity

The identity name is **StewardBench — Benchmark Mark**. Its combined symbolism
is:

- a gauge for measurement and benchmarking;
- a check mark for verification; and
- connected nodes for network operations.

The associated idea is **benchmark, compare, improve**. The wordmark is
`StewardBench`. Navy and blue are the primary identity colors. Green remains
primarily a semantic GOOD/PASS color and should not dominate the wordmark.
Typography should use a clean sans-serif direction comparable to Inter or
Source Sans, subject to later licensing and implementation review.

## Required finalized assets

When approved source artwork is available, this directory should contain:

- full horizontal logo;
- standalone app icon;
- circular icon where useful;
- simplified monochrome/small icon;
- favicon;
- dark-background logo variant; and
- palette/reference sheet with color values, clear space, and minimum sizes.

File names, source/master formats, and generated variants should be documented
alongside the assets. SVG should be preferred for scalable masters when the
approved artwork is delivered, with raster favicon/app variants generated as
needed.

## Guardrails

No final SVG has been fabricated during the documentation phase. Minor geometry
or spacing adjustments are permitted only for implementation constraints; they
must not redesign the approved gauge/check/network-node concept. UI color usage
is specified in [UI/UX](../../ui-ux.md).
